# Direct dependencies for the whole project, including analysis and test scripts.

#
# Mac target: Apple Silicon (arm64), macOS 14+, standard CPython 3.13 or 3.14.
# The scripts use sys._is_gil_enabled(), which requires CPython 3.13+.
# These pins are not an Intel Mac installation configuration.
#
# Create a NEW virtual environment on the Mac; do not copy the Linux .venv.
# From the project root, for example:
#   python3.13 -m venv .venv
#   source .venv/bin/activate
#   python -m pip install --upgrade pip
#   python -m pip install -r requirements.txt
#
# PySpark also needs Java installed separately (JDK 17 or 21 recommended),
# with JAVA_HOME set. See:
# https://spark.apache.org/docs/4.1.2/api/python/getting_started/install.html
# Set PYSPARK_PYTHON and PYSPARK_DRIVER_PYTHON to the Mac venv's Python.
# Run the spectrum predictor from predict/ with the project root on PYTHONPATH.
# The Linux-only TORCH_ROCM_AOTRITON_ENABLE_EXPERIMENTAL setting is not needed.
